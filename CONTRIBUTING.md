# Contributing to Mergington High School Extracurricular Activities

Welcome! We are excited that you want to contribute to the Mergington High School extracurricular activities website. Whether you are a teacher adding a new club or a developer fixing a bug, your help keeps our community vibrant and organized.

Please follow these guidelines to make collaboration smooth and effective for everyone.

## Getting Started

1. **Fork and Clone:** Fork the repository to your own GitHub account and clone it to your local machine or open it in GitHub Codespaces.
2. **Create a Branch:** Always create a new branch for your changes. Do not work directly on the `main` branch.
   * Feature branches: `feature/club-name-update`
   * Bug fixes: `fix/issue-description`

## Making Changes

* Keep your code clean, well-commented, and easy to read.
* Test your changes locally before submitting a pull request to ensure nothing breaks.
* Follow the existing formatting and style of the project.

## Submitting a Pull Request

1. Push your changes to your cloned fork on GitHub.
2. Open a Pull Request (PR) targeting the `main` branch of this repository.
3. Provide a clear and descriptive title and description explaining what your changes do.
4. Link any related issues in your PR description.

## Code of Conduct

Please be respectful, supportive, and inclusive. We are working together to build a great resource for our school community!
